# Cross-Analysis Prompt (Title Study) v1.0.0
Realiza el cotejo cruzado entre las fuentes de información:
- Rol: CBR vs SII vs Certificado de Informaciones Previas vs Plano
- Propietario: Dominio Vigente vs SII vs Escritura
- Superficie: Título vs Certificado SII vs Plano
- Deslindes: Escritura original vs Inscripciones posteriores
- Gravámenes: Certificado de Hipotecas y Gravámenes vs Anotaciones marginales

Clasifica cada comparación en:
- CONSISTENT (total concordancia)
- DISCREPANCY (diferencia o conflicto entre fuentes)
- PARTIAL (concordancia parcial)
- INSUFFICIENT_EVIDENCE (fuentes ausentes)
